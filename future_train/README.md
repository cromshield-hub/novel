# 미래로 가는 기차

시간을 멈춘 어머니의 지구와, 시간을 앞질러 간 아들의 이야기. 우주를 가꾸는 기차를 배경으로 한 SF 단편 원고입니다.

## 파일 안내

| 파일 | 역할 |
| --- | --- |
| `미래로_가는_기차_단편_초고.docx` | 최신 Word 원고(본문과 부록 수록) |
| `manuscript_rewrite.md` | **편집 기준 원문**. 1부 도현, 2부 서진, 에필로그, 부록 |
| `characters_timeline.md` | 등장인물과 확정 연대기, 사건 순서 |
| `worldbuilding.md` | 기차, 테라리움, 시간, 위상 변환, 개입 규칙 |
| `AGENTS.md` | Codex가 이어 쓰기 전 확인할 집필 지침 |
| `build_story_doc.py` | Markdown을 Word 문서로 조판하는 스크립트 |
| `requirements.txt` | Word 문서 생성에 필요한 Python 패키지 |

## 편집과 Word 재생성

```bash
python -m pip install -r future_train/requirements.txt
python future_train/build_story_doc.py
```

스크립트는 자신의 폴더에서 `manuscript_rewrite.md`를 읽고 동일 폴더에 `미래로_가는_기차_단편_초고.docx`를 덮어씁니다. 본문을 수정할 때 두 파일을 함께 커밋하세요.

## 현재 이야기의 중심

도현은 열여덟 살에 자신의 세계가 기차의 테라리움임을 알고 밖으로 나온다. 아버지의 정체와 죽음을 알게 되어 견습 정원사가 된 뒤 어머니가 있는 지구의 시간을 멈추고, 다른 우주에서 연구와 사랑을 경험한다. 사랑과 구원을 명분으로 타인의 시간과 삶을 결정했던 자신의 잘못을 받아들인다. 서진은 그 사실에 분노하지만, 이해와 관계를 다시 선택하는 과정은 행동으로 보여준다.

## 단편과 장편

현재 원고는 **단편 버전**입니다. 장편 확장 시 세부 사건은 달라질 수 있으므로 기존 단편에 모든 확장 아이디어를 끼워 넣지 않습니다. 버전별 의도와 바뀐 설정을 명시하며 별도 문서 또는 브랜치에서 작업합니다.
