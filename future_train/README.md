# 미래로 가는 기차

시간을 멈춘 어머니의 지구와, 시간을 앞질러 간 아들의 이야기. 우주를 가꾸는 기차를 배경으로 한 단편 **SF 드라마**입니다. 인물의 감정과 관계, 선택을 중심에 둡니다.

**현재는 한 챕터씩 개정 집필 중입니다.** 1장 「정원사」 초안을 본문과 DOCX에 반영했고, 2장 이후는 기존 원고입니다. 인물·문체·연대기·사건·킥은 `characters_timeline.md`, 세계관은 `worldbuilding.md`, 이어 쓰기 기준은 `AGENTS.md`를 따릅니다.

## 파일 안내

| 파일 | 역할 |
| --- | --- |
| `미래로_가는_기차_단편_초고.docx` | 현재 Word 원고. 1장 개정 초안 반영, 2장 이후 개정 대기 |
| `manuscript_rewrite.md` | 현재 본문 원본. 1장 개정 초안 반영, 2장 이후 개정 대기 |
| `characters_timeline.md` | 최신 인물·문체·연대기·사건·킥 설계. 확정·제안·미정 구별 |
| `worldbuilding.md` | 기차, 테라리움, 시간, 위상 변환, 개입 규칙 |
| `AGENTS.md` | Codex가 이어 쓰기 전 확인할 집필 지침 |
| `build_story_doc.py` | Markdown을 Word 문서로 조판하는 스크립트 |
| `requirements.txt` | Word 문서 생성에 필요한 Python 패키지 |

## 편집과 Word 재생성

```bash
python -m pip install -r future_train/requirements.txt
python future_train/build_story_doc.py
```

스크립트는 자신의 폴더에서 `manuscript_rewrite.md`를 읽고 동일 폴더에 `미래로_가는_기차_단편_초고.docx`를 덮어씁니다. 본문을 수정할 때 두 파일을 함께 커밋하세요.

## 현재 이야기의 중심

도현은 2019년 열아홉 살에 기차로 나온다. 사흘 만에 귀가해 우는 어머니를 만난 그날 밤, 살려야겠다고 결심하고 다시 나가 고향의 시간을 멈춘다. 스물두 살에 새 지구 조성을 마치고, 스물여섯 살에 첫 약이 실패한다. 어머니는 돌아올 때마다 자라고 늙어가는 아들의 삶을 함께 살지 못하는 고통 속에서, 도현과 같은 시간을 살며 끝까지 그의 엄마로 남기를 원한다. “엄마는 도현이의 엄마인 채로… 살고 싶어.”에는 말하지 못한 ‘죽고 싶어’가 남는다. 도현은 시간 재개 뒤에도 돌봄과 연구를 이어가다가 스물일곱 살에 임종을 지킨다. 새 지구의 결말은 2027년, 고향은 2020년이다.

설계는 감정선과 큰 사건을 유지하기 위한 기준이다. 세부 날짜와 왕복·배속, 장면 간격을 기계적으로 맞추기보다 인물의 마음과 장면의 여백을 우선한다.

우주를 관찰하는 도현은 건조한 평서체로, 도현을 관찰하는 서진은 따뜻하고 적극적인 경어체로 서술한다. 두 사람의 현재는 첫 약 실패 시점이며, 그 이전은 회고, 그 이후 약 1년은 현재를 따라 진행한다. 서진의 적극성은 기존 사건을 바라보는 내레이션에 담는다. 장례 후 자수와 처분을 거쳐 재회하며, 고향의 인간적인 생활과 다른 우주의 관리자·관찰자 방문은 허용된다.

## 단편과 장편

현재 원고는 **단편 SF 드라마**, 향후 장편 구상은 **소프트 SF** 방향입니다. SF의 핵심 규칙은 유지하되 원리와 계산은 인물의 선택과 결과를 이해하는 데 필요한 만큼 다룹니다. 장편 확장 시 세부 사건은 달라질 수 있으므로 기존 단편에 모든 확장 아이디어를 끼워 넣지 않습니다. 버전별 의도와 바뀐 설정을 명시하며 별도 문서 또는 브랜치에서 작업합니다.
